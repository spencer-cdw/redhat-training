# Build Configs (Source to Image)

Openshift supports build configs.
Build configs replace your ci/cd. By just providing a git repo and a build config, openshift will 'compile' or build a container image to deploy. 

### Automatic Language Detection
Similar to old hashicorp 'otto'.
